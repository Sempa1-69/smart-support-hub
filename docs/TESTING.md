## Дополнительно

- Dark/Light переключается и выбор сохраняется после обновления.
- Фильтр инцидентов по статусу показывает только выбранный статус.
- Добавление внедрения с неверной версией (например, `1.2`) даёт сообщение об ошибке.
- Подсказка следующей версии: patch v1.2.1 → v1.2.2, minor → v1.3.0, major → v2.0.0.
